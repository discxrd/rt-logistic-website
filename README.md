# RT Logistic website

A multilingual website for a logistics company, with English, Latvian, and Russian content. The frontend is a React/TypeScript app and the backend provides the supporting API. Docker Compose is included for deployment.

## Run

Review the service configuration, create local environment files from the examples required by each service, then start the stack:

```sh
docker compose up --build
```

The deployment archive and environment files are excluded. Ask the site owner for credentials through an approved channel.
